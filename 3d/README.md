独立的3D游戏，原仓库根目录的2D版及其存档不变。网页静态部署即可，不需要 Meshy API、数据库或外部 CDN。

## 角色与毛绒效果

- 钱钱 Fuzzy：蓝领巾站立外形、双脚跑步，使用 `assets/chars/fuzzy/v5-test/fuzzy-v5-plush-run-test.glb`。优先读取 gzip，失败回退到 GLB。
- `fuzzy-plush-fur.js` 添加18万根细毛，保留原模型、骨骼和动作，保护眼嘴与领巾。复用 `assets/chars/fuzzy/v6-test/textures/fuzzy-ivory-short-fur-v1.png`；该路径保留纹理版本，不代表启用四足模型。
- 地址加 `?shortFur=1` 使用旧版3.6万根短毛，加 `?flatFur=1` 关闭附加毛发。纹理失败时保留基础模型，切换角色时释放附加毛发。
- 涂涂 Doodle：使用 `assets/chars/doodle/v4-test/doodle-green-tail-test.glb`，绿色扇形短羽尾，保留原身体、8根骨骼和9个动作。背部旧尾根灰斑仍存在，不视为美术最终定稿。
- Fuzzy 模型失败时可用备用造型；Doodle 模型失败时禁用其开始按钮，可以切换回 Fuzzy。
- 两个角色由项目所有者在 Meshy 私有许可模式下生成。使用受生成时套餐及参考素材权利约束，游戏使用者不应单独再分发角色模型。

## 当前规则

- 四张地图：中国竹林 → 日本樱花林 → 欧洲针叶林 → 亚马逊雨林；每张20,000米，通关后解锁下一张。
- 简单／普通／困难／挑战：5／4／3／2颗心，速度倍率1／2／3／5。地图基础速度24／26／28／30米每秒，随进度增加。高倍速提前加载障碍，维持小动物至少1.2秒预警。
- 每3,000分恢复1颗心，不超过上限；每500米切换一个可选短任务。
- Fuzzy 冲撞障碍；Doodle 跳起后可滑翔。按住 W/↑ 加速，左右换道，空格跳跃，下键滑行。
- 快速滑动在抬手时也识别方向；一次手势只执行一次，短点触跳跃。跳跃与下滑支持0.18秒落地输入缓存，最后输入优先。
- 四地图分别出现松鼠、绣眼鸟、野兔和小巨嘴鸟。小动物迎面冲来时有跑道标记和提示，可换道、跳跃或冲撞避开；冲撞动物不奖励破坏障碍分数。
- 红莓恢复1颗心，满血加80分；金种子加120分；毒蘑菇扣护盾或生命；蛛网延长技能冷却。Fuzzy 冲撞保护可免受后两者影响。
- 护盾、磁铁、双倍积分及技能重置在四地图生效。磁铁不吸附负面道具。
- 同跑道精准跳过障碍或滑过树枝加10分，三连额外加30分；碰撞断连，换安全跑道不领奖也不断连，冲撞不计精准越障。
- 新动物、道具和场景图缺失时保留备用造型，不应白屏。

## 本地验证

从仓库根目录执行：

```sh
node --test 3d/engine.test.mjs 3d/gestures.test.mjs tests/*.test.mjs
python3 -m http.server 4197 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4197/3d/>。地址加 `?test` 可启用确定性检查接口 `window.__runnerTest` 与 `window.advanceTime(ms)`。

发布前覆盖 Fuzzy 加载及细毛、Doodle 加载/滑翔、角色切换、四档实际速度、缺毛纹回退、桌面和竖屏画面。运行修改集中在 `engine.js`、`main.js`、`world.js`、`gestures.js`、两个毛发模块、`index.html`、`style.css` 和上述资源。

本地通过不等同线上部署成功；发布后须检查 Pages 提交及公开资源。Google Drive 备份若没有独立成功证据，状态为 `backup not verified`。

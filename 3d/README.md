# 森林学校 3D 跑酷 · 线上试玩版

入口：`https://willzhan1983.github.io/forest-school-runner/3d/`。此目录是独立的 3D 游戏，原仓库根目录的 2D 版和存档不变。网页静态部署即可，不需要 Meshy API、数据库或 CDN。

## 当前参数

- 四张地图：中国竹林 → 日本樱花林 → 欧洲针叶林 → 亚马逊雨林。每张 20,000 米，通关后解锁下一张。
- 简单／普通／困难／挑战：5／4／3／2 心；速度倍率 1／1.5／2／2.5。地图基础起速 24／26／28／30 米/秒，并随距离增加。
- 每 3,000 分恢复 1 心（不超过难度上限）。每 500 米切换一项可选短任务。护盾、磁铁、双倍积分与技能重置保留现有规则。
- Fuzzy 冲撞与 Doodle 空中滑翔可在开始页选择。四张地图的近景植物、障碍与收集物使用已验证的测试版素材。

## 素材与试玩边界

- 仅包含网页运行所需文件及优化后的 GLB；原始 Meshy 工程、参考图、制作脚本、测试输出和备份没有上传。
- Fuzzy 和 Doodle 模型由项目所有者在 Meshy 的私有许可模式下生成。Meshy 的[资产使用说明](https://help.meshy.ai/en/articles/9992001-can-i-use-meshy-assets-commercially-license-copyright-explained)按生成时套餐和参考素材权利区分授权；游戏使用者不应将这些角色模型单独再分发。
- Doodle 背部贴图还留有旧尾根灰斑；这版是公开试玩，不代表角色美术最终定稿。
- 浏览器自动检查已覆盖桌面、竖屏和横屏。真实 iPhone/Android 的帧率、发热和续航仍待试玩反馈。
- 若图片或 Fuzzy 模型加载失败，原有 3D 形状会回退；Doodle 模型加载失败时，Doodle 的开始按钮会禁用，Fuzzy 仍可玩。

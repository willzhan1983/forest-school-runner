# 森林学校大冒险 · Forest School Runner

一款给小朋友做的 2D 横版跑酷游戏。**单文件 HTML，零依赖**，浏览器打开即玩。

## 在线玩

👉 **https://willzhan1983.github.io/forest-school-runner/**

## 角色

| 角色 | 中文名 | 英文名 | 专属技能 |
|---|---|---|---|
| 灰白猫 | 钱钱 | Fuzzy | **冲刺** —— 向前猛冲，撞碎障碍并短暂无敌（CD 3 秒） |
| 黄绿猫头鹰 | 涂涂 | Doodle | **滑翔** —— 空中二段跳，长按展翅缓降 |

## 难度

进入游戏前可选四档，选择会被记住。

| 难度 | 速度 | 生命 | 双连障碍 | 适合谁 |
|---|---|---|---|---|
| 🟢 简单 | 4.4 → 8.0 | **5 颗心** | 无 | 小朋友 / 想轻松跑 |
| 🔵 普通 | 5.6 → 12.0 | 3 颗心 | 22% | 标准手感 |
| 🟠 困难 | 6.2 → 13.5 | 2 颗心 | 34% | 熟练玩家 |
| 🟣 噩梦 | 7.0 → 14.5 | **1 颗心** | 42% | 自找苦吃 |

## 玩法

- 自动向前奔跑，穿越**森林 → 教室 → 树屋**三个场景，循环推进
- 收集**橡果**和**书本**得分，撞到障碍扣一颗心
- 吃到**护盾 / 磁铁 / 双倍分**三种道具
- 有**昼夜循环**（约 50 秒一天）和实时合成的背景音乐
- 背景音乐在**菜单页就开始播放**，一路延续到游戏和结算页不会中断
- 左上角音符按钮可随时开关音乐，开关状态会被记住

> 浏览器规定音频必须由用户手势唤醒，所以**打开页面后需要先点一下画面**，
> 之后音乐就会自动响起来。这是所有网页游戏的共同限制，不是本游戏的问题。

## 操作

| | 键盘 | 触屏 |
|---|---|---|
| 跳跃 | `空格` / `↑` / `W` | 点击屏幕 |
| 二段跳 | 再按一次（仅涂涂） | 再点一次 |
| 滑翔 | 长按跳跃（仅涂涂） | 长按屏幕 |
| 滑铲 | `↓` / `S` | 向下滑动 |
| 技能 | `D` / `Shift` | 右下角技能键 |
| 暂停 | `P` / `Esc` | 左上角暂停键 |
| 选难度 | `1` `2` `3` `4` 或 `↑` `↓` | 点击难度按钮 |

## 本地运行

直接双击 `forest-school-runner.html`，或：

```bash
open forest-school-runner.html
```

无需安装任何依赖，也无需联网。

## 技术

- 单文件：HTML + CSS + 原生 JavaScript，全部内联
- 渲染：Canvas 2D，程序化绘制 + base64 内嵌角色立绘
- 音频：Web Audio API 实时合成（三层循环 BGM + 音效），无音频文件
  - BGM 为 C 大调五声音阶 32 步 A/B 句结构，配 C-Am-Fmaj7-G 和声，13.4 秒一循环
  - 入夜后主旋律降八度、整体音量降 45%
  - `Audio2.kick()` 在任意手势时唤醒 AudioContext，绕开自动播放策略
- 存档：`localStorage`（最高分 `fsr_best`、难度 `fsr_diff`、音乐开关 `fsr_music`）
- 适配：键盘 + 触屏，窗口自适应，竖屏可玩

## 二次修改

打开 HTML 搜索关键词即可改：

| 想改什么 | 搜什么 |
|---|---|
| 难度数值 | `var DIFF` |
| 角色配色 | `colors:{fur:`（猫）/ `colors:{top:`（猫头鹰） |
| 场景配色 | `var THEMES` |
| 物理手感 | `GRAVITY` / `MAX_FALL` |
| 道具时长 | `POWERUP_META` |
| 背景音乐 | `MUSIC_MEL` / `MUSIC_BASS` / `beat` |
| 昼夜快慢 | `dayPhase`（`% 50` 即 50 秒一天） |
